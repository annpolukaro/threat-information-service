# Threat Information Service

REST API сервис для хранения и обмена информацией об угрозах, реализованный на Go в соответствии с OpenAPI 3.0.

## Технологии

- Go
- PostgreSQL
- Docker и Docker Compose
- OpenAPI 3.0

## Возможности

- Создание информации об угрозе
- Получение информации по MD5-хешу
- Обновление информации об угрозе
- Валидация входных данных
- Обработка HTTP-ошибок
- Ограничение количества запросов (Rate Limiting)
- Unit- и интеграционные тесты

Модель угрозы содержит MD5-хеш, название, описание, тип угрозы, уровень критичности и временные метки.

## Запуск

Для запуска необходимы Docker и Docker Compose.

1. Создать файл `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

2. Запустить сервис:

```bash
docker compose up --build -d
```

API будет доступен по адресу `http://localhost:8080` при стандартной конфигурации.

## API

| Метод | Маршрут | Описание |
|---|---|---|
| POST | `/info` | Создание записи об угрозе |
| GET | `/info/{md5}` | Получение информации по MD5 |
| PUT | `/info/{md5}` | Обновление записи об угрозе |

Пример создания угрозы:

```json
{
  "md5": "5d41402abc4b2a76b9719d911017c592",
  "name": "Test Trojan",
  "description": "Example threat",
  "threat_type": "trojan",
  "severity": "high",
  "first_seen_at": "2026-01-15T10:30:00Z"
}
```

Возможные HTTP-статусы: `200`, `201`, `400`, `404`, `409`, `429`, `500`.

Полная спецификация API находится в `api/openapi.yaml`.

## Тестирование

Запуск тестов:

```bash
go test ./...
```

Для выполнения интеграционных тестов репозитория необходимо указать переменную `DATABASE_URL` с подключением к отдельной тестовой базе PostgreSQL.

## Остановка

```bash
docker compose down
```
