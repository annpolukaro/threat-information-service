# Threat Information Service

REST API-сервис для хранения и обмена информацией о компьютерных угрозах по MD5-хешу файла. Разработан на Go с использованием PostgreSQL в соответствии со спецификацией OpenAPI 3.0.

## Технологии

- **Go** — REST API, бизнес-логика и валидация данных.
- **PostgreSQL 17** — хранение информации об угрозах.
- **Docker и Docker Compose** — контейнеризация приложения.
- **Nginx** — обратный прокси-сервер и HTTPS.
- **OpenAPI 3.0** — спецификация HTTP-интерфейса.
- **Go testing** — модульное и интеграционное тестирование.

## Возможности

- Создание информации об угрозе.
- Получение информации по MD5-хешу.
- Обновление существующей записи.
- Проверка корректности входных данных.
- Обработка HTTP-ошибок.
- Авторизация по API-ключу.
- Ограничение частоты запросов (rate limiting).
- Защита соединения с помощью HTTPS.
- Unit- и интеграционные тесты.

## Модель угрозы

Каждая запись содержит следующие поля:

| Поле | Описание |
|---|---|
| `md5` | MD5-хеш файла, уникальный идентификатор угрозы |
| `name` | Название угрозы |
| `description` | Описание угрозы |
| `threat_type` | Тип угрозы |
| `severity` | Уровень опасности |
| `first_seen_at` | Дата первого обнаружения |
| `created_at` | Дата создания записи |
| `updated_at` | Дата последнего обновления |

Поддерживаемые типы угроз:

`trojan`, `virus`, `worm`, `ransomware`, `spyware`, `other`.

Уровни опасности:

`low`, `medium`, `high`, `critical`.

MD5-хеш должен содержать ровно 32 шестнадцатеричных символа.

## Запуск проекта

Для запуска необходимы Docker и Docker Compose.

### 1. Настройка окружения

Создать файл `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

Указать в `.env` необходимые параметры подключения к PostgreSQL и API-ключ.

Не следует публиковать `.env` в репозитории.

### 2. Запуск контейнеров

```powershell
docker compose up --build -d
```

### 3. Проверка состояния

```powershell
docker compose ps
```

Проверка доступности API:

```powershell
curl.exe -k https://localhost/healthz
```

Ожидаемый ответ:

```json
{
  "status": "ok"
}
```

API доступен по адресу:

`https://localhost`

В локальной конфигурации используется сертификат, которому система может не доверять. Поэтому в примерах применяется `-k` для отключения проверки сертификата. Для промышленного развёртывания необходимо использовать доверенный сертификат и не отключать его проверку.

## REST API

| Метод | Маршрут | Описание | Авторизация |
|---|---|---|---|
| POST | `/info` | Создание информации об угрозе | API-ключ |
| GET | `/info/{md5}` | Получение информации об угрозе | Не требуется |
| PUT | `/info/{md5}` | Обновление информации об угрозе | API-ключ |
| GET | `/healthz` | Проверка работоспособности | Не требуется |

### Авторизация

Для создания и обновления информации используется HTTP-заголовок:

`X-API-Key`

Ключ должен соответствовать значению `API_KEY`, заданному в конфигурации сервиса.

При отсутствии или неправильном значении ключа сервер возвращает:

`401 Unauthorized`

### Создание угрозы

**POST /info**

Пример тела запроса:

```json
{
  "md5": "5d41402abc4b2a76b9719d911017c592",
  "name": "Trojan.Win32.Generic",
  "description": "Вредоносная программа",
  "threat_type": "trojan",
  "severity": "high",
  "first_seen_at": "2026-01-15T10:30:00Z"
}
```

При успешном создании возвращается HTTP `201 Created`.

При попытке создать запись с уже существующим MD5 возвращается HTTP `409 Conflict`.

### Получение угрозы

**GET /info/{md5}**

Пример:

```powershell
curl.exe -k https://localhost/info/5d41402abc4b2a76b9719d911017c592
```

При успешном выполнении возвращается HTTP `200 OK` и информация об угрозе.

Если запись не найдена, возвращается HTTP `404 Not Found`.
